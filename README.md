## 🛠️ Troubleshooting

- Ensure the downloaded archive is named exactly **`WindowsBulkFileRenamer.zip`**.
- Extract it before running **`WindowsBulkFileRenamer.exe`**.

- Preview names are wrong: review rule order and numbering options.
- Rename fails: check file permissions and whether files are open.
- Special characters cause errors: avoid characters not permitted in Windows filenames.
- **Download returns 404:** The release has not yet been published or its asset is not named `WindowsBulkFileRenamer.zip`.
- **Windows displays a warning:** Verify the publisher and file provenance before proceeding; never bypass security warnings blindly.
